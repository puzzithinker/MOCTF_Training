## 逐檔線上幻燈收 spatial

- **W1**：先「版本 → CVE 清單」的思維
- **W2**：SQL 注入为「SQL 語义」遊戲; NoSQL 為「全文查找」
- **W3**：命令注入的「管道符」由 execve/fork 機制解釋
- **W4**：php://filter 是 PHP 的「任意檔案全家桶）
- **W5**：SSRF 是「讓伺服器替你發請求」；XXE 是「讓 XML 解析器幫你讀檔」
- **W6**： deserialize 的本質是「重構物件, 連帶箇 destruction」
- **W7**：鏈的思考方式 = 「不調自一個步在上一步開啟的關門」
- **W8**：找漏洞與修補是同一件事的兩面；AI 只是放大器

## 常見學員疑問（開場預答）

1. 「我應該學哪個語言？」 PHP/Python/Java 佔 Web CTF 70% 題型; Node(Express) 在複合邏輯與原型污染類重要。
2. 「sqlmap 為什麼不如手工？」 因為 CTF 題 90% 帶 WAF 或字元限制；工具跑不動，手工 payload 才能穿。
3. 「Nginx 版本影響大嗎？」 影響 Nginx configuration（require `/etc/nginx/nginx.conf`），不常為 attack surface。
4. 「賽場遇到 0day 怎麼辦？」 99% 不是 0day——是你漏掉某個隱藏端點。重掃 1 次 pattern。

## 模組驗收

- 能脫稿回答: 「SSRF 如何轉 MySQL?」「SSTI 引擎誰與最小 payload?」「php://filter 可否直接寫檔?」
- 能在 20 分鐘內完成一個「無 WAF 的 SQL 注入」至拿 flag 的全流程（見練習題集 8）。
- 能對一份 100 行 PHP 源碼進行 5 分鐘口頭審計並指出 ≥ 2 個漏洞（見 W8 大綱）。
