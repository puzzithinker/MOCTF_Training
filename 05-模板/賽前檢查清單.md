# 賽前檢查清單（賽前 7 天 → 開賽前 5 分鐘）

> 純操作性文件。印出來貼在螢幕邊，每完成一項打 ✔。
> 對應課程：`04-攻防平台操作.md`（流程面）、`01-CTF環境設置及準備.md`（工具面）。

---

## A. 賽前 7 天

- [ ] 讀完賽事規則：AI 允許性、組隊人數、flag 格式
- [ ] 分組定案（3~5 人），並確認時區與線上/線下參賽安排
- [ ] 列出本隊擅長朝向：Web / Pwn / Crypto / Reverse / Misc / Forensics
- [ ] 安排「賽前集訓」6 小時（Web 模組 + Pwn 模組基本章節）
- [ ] 所有教材與靶場（vulhub、sqli-labs、upload-labs）拉到 Kali VM

## B. 賽前 1 天

### 工具面

- [ ] Kali VM 快照 `BASE-<date>`（這一條最重要）
- [ ] `pip install pwntools ROPgadget` 若有更改都要更新
- [ ] `checksec` / `ROPgadget` / `one_gadget` 已可用
- [ ] SecLists、fuzz 系列字典目錄完整（見 01 §6）
- [ ] Burp / foxy proxy 設置完成
- [ ] ClientTools（XSSH / LocalProxy）能開
- [ ] VS Code / Obsidian 就位

### 心理面

- [ ] 睡眠：確保當天有 7+ 小時 
- [ ] 筆記模板已挂在 `05-模板/Writeup報告模板.md`
- [ ] AI prompt 庫已造稿（見 `05-模板/AI提示詞庫.md`）
- [ ] 賽程時間與澳門時間對照表已寫

## C. 開賽前 30 分鐘

- [ ] 平台登入 OK，查 team / flag 格式 / scoring 規則
- [ ] 開啟 Discord/官方群，確認沒有「延賽/相似改動」訊息
- [ ] 測試 VPN：可以連 「測試靶機」
- [ ] PoC 檢查下本隊工具是否可以整體輸出到外網

## D. 開賽時

- [ ] 05-模板 的復盤工具到位
- [ ] 隊口頭分工（誰 web / Pwn /的信息）
- [ ] 每 15 分鐘根據 02-方法論 §4.1 的 分鐘規則 走位
- [ ] 30 分鐘站會（03-04 分鐘；內容：現在卡點、下一目標）

## E. 收 flag

- [ ] flag 本身複製後 trim
- [ ] 驗證（大小寫、前後 `{}`、動態 flag 版本）
- [ ] 一次正確提交

## F. 賽後

- [ ] 把每個虛 flag記錄在 05-模板/Writeup報告模板.md
- [ ] 賽後 24 小時內完成「self-completion」
