# P7 · MIPS32 架構基礎（20 分鐘）

> 為什麼 CTF 要學 MIPS？——大量嵌入式/Router Firmware 为 MIPS（MIPS Big-Endian 或 MIPSel），賽場偶爾出 MIPS 的 ROP/格式化字串。
> 目標：能讀懂 MIPS 反彙編、知道 `syscall` 的 Linux 呼叫號（MIPS O32 是 `4000+n`）、能復現一個「`.got` ROP」。

---

## 1 · MIPS vs x86 初步感覺

| 項目 | MIPS（32 位） | x86-64 |
|---|---|---|
| 寄存器 | 通用 32 個： `$zero/$at/$v0/$a0..$a3/$t0..$t9/$s0../$gp/$fp/$sp/$ra` | rax/rbx/… |
| 退化指令格式 | 固定 4 位元組 | 可變長 |
| 函數返回 | `jal` 設 `$ra`；函數結尾 `jr $ra` | `ret` |
| syscall | `syscall` 指令 + `$v0 =塗pipeline` | `syscall` 指令 + `rax = numbers` |
| 記憶體定址 | `lw/sw rt, offset(base)` 需先 load 位址 | `mov rax, [rbp+offset]` 直接 |

> MIPS 標註用途的兩個要點：`$ra`（return address 暫存器）**直接存放返回位址**，不是棧；BUT CTF 是溢位讓它 被 overwritten。

## 2 · 看 MIPS 反編譯時關鍵的三條（賽場侶最需要的技能）

```asm
li   $a0, <string_addr>      ; 第一個參數
li   $a1, 0                  ; 第二個參數
jal  strcpy                  ; 呼叫
move $v0, $t2                ; 返回值
sysycall                     ; 系統呼叫
```

- `$a0..$a3` = 參數（Web `rdi->rdx` 之內）；
- 返回 `$v0`，syscall 虛台的 `$v0 = 標號`；
- 溢位術語跟 x86 類似，只是寄蔑順序不同。

### MIPS 呼叫約定

| 暫存器 | 用途 |
|---|---|
| `$a0`..`$a3` | 函數前 4 個參數 |
| `$a4`..`$a7`/棧 | 更多參數走棧 |
| `$v0` | 返回值 / syscall 呼叫號 |
| `$ra` | 返回地址（內存需保存） |
| `$fp` | 棧楨基準 |
| `$sp` | 棧頂 |

## 3 · MIPS syscall：呼叫號 = `4000 + syscall number`

Linux MIPS **O32 ABI** 的呼叫號是 `4000 + 標準號`：

| 標準號 | 功用 | MIPS=$v0 |
|---|---|---|
| 0 | read | 4000 |
| 1 | write | 4001 |
| 2 | open | 4002 |
| 3 | close | 4003 |
| 11 | execve | **4011** |
| 4 | exit | 4004 |

> O32 ABI 的 shellcode `execve("/bin/sh",0,0)`：`$v0=4011`，`$a0=/bin/sh 位址`，`$a1=0`，`$a2=0`。
> 賽場練習 40 需要學員手構「**MIPS 之 execve shellcode**」或 ret2`syscall`。

## 4 · MIPS shellcode 样板（execve）

```asm
; execve( "/bin/sh", 0, 0 )
li  $t5, 0x68616e00        ; "/bin/sh\0" 內部 (以 int 拼)
sw  $t5, -8($sp)
li  $t6, 0x622f2f2f
sw  $t6, -4($sp)
li  $a0, -8($sp)           ; 注意 load 的 addition
li  $a1, 0
li  $a2, 0
li  $v0, 4011              ; syscall execve
syscall
```

> pwntools 有 mips shellcraft：`shellcraft.mips.linux.sh`，會為你我編寫。有些簡單的字串直接用大端碼模組。

## 5 · 賽場流：開 mips 的工具巡

```bash
# 交叉編譯（Ubuntu 20.04 有）
sudo apt install gcc-mips-linux-gnu binutils-mips-linux-gnu
sudo apt install gcc-mipsel-linux-gnu binutils-mipsel-linux-gnu   # 小端
sudo apt install gdb-multiarch  # gdb 支援 mips
# 靜態執行（qemu-user-static）
apt install qemu-user-static
```

### 5.1 靜態交叉編譯

```bash
mipsel-linux-gnu-gcc -fno-stack-protector -no-pie hello.c -o hello.mipsel
mipsel-linux-gnu-gcc -static hello.c -o hello.mipsel.static
# 動態跑（示靜態 libc）
qemu-mipsel -L /usr/mipsel-linux-gnu hello.mipsel
```

### 5.2 檢查

```bash
file hello.mipsel
checksec hello.mipsel
# MIPS 常無 canary，架構為 `DYNAMIC`
fawn ROPgadget --binary hello.mipsel --only "pop|jp|ret"    # pop gadget
```

## 6 · MIPS ret2libc：寫思路

```text
 leveraging: 已知 syscall 入口 (GOT) & /bin/sh 位址 ( GNU libc 就可直接由 libc 搜 ,
遠端硬要在 local libc path 生成 Gadget 的推運
ví dụ( ep еще ret2libc)：
  ret2 (` $sp`) → `pop $ra; pop $s0; …; jr $ra` gadget 幾乎處 …
```

> MIPS 的「ROP gadget 幾乎你在 x86 下的 reason」並不在相second for 熟手，「**直接覆盖 `$ra`**」 是整條鏈的入口，之後 j都 `jalr` 可控。
