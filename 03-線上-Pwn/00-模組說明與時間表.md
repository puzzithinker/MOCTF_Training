# Pwn 攻防模組 · 模組說明與時間表（3 小時 · 線上）

> 對應大綱「Pwn 攻防模組（3小時）」+「Pwn 題目 Code Review 與 Patch 實作」。
> 建議環境：各自一台 x64 Linux VM（Ubuntu 22.04/24.04），分別檢驗 `pwn`、`pwntools`、`gdb`、`ROPgadget`。二進制的環境固定使用 **不開 ASLR（`setarch -R`）** 的一鍵 IP 學坊練習。

## 逐檔簡介

- **01 二進制基礎**：ELF 的 sections 與 segments、`readelf`、`nm`、x64 calling convention、棧佈局圖。
- **02 保護機制**：Canary/NX/PIE/RELRO 的行為與 `checksec` 解讀；開/關的 gcc 旗標。
- **03 pwntools**：`process/remote`、`sendline/pack/flat`、`ELF().plt/got`、`ROPgadget`、`p64`。
- **04 棧溢出與 ret2libc**：經典例題，把「leak libc→shadow ret2libc」三版全走一遍。
- **05 命令注入 & C 邏輯追蹤**：`system()` 的程序狀態；`strace`/`ltrace`；`objdump -d -M intel` 檢視反編譯。
- **06 格式化字串**：`%p` leak → `%n` 寫 → GOT overwrite；`fmtstr_payload`.
- **07 MIPS32**：32 些 loads, `mipsel`，sys 內 formulate 從 syscall(4000+NR)。
- **08 Code review**：c 源碼審計清單、可重用的 flags、真正的 heap 挑戰初uent。

## 逐檔環境要求

- `gcc`（含 32 位元搭建）:
  ```bash
  sudo apt install -y build-essential gcc-multilib libc6-dev-i386
  ```
- `pwntools`: `pip install pwntools`
- `gdb + pwndbg`: `git clone https://github.com/pwndbg/pwndbg && cd pwndbg && ./setup.sh`
- `ROPgadget`：`pip install ROPgadget`
- `checksec`：納入 pwntools

## 模組驗收

1. **ret2libc 全通**:  在 04 章之後要能在 30 分鐘內通話連過 2 筆。
2. **格式化字串 GOT 改寫**: 完成 06 章的「改 puts@GOT → system」達成 shell。
3. **MIPS32**: 完成 07 章的一條 `mipsel` 挑戰（`syscall 4000+` 的思路完整 show 出）。
4. **Code-Re 上 patch**： 給一段 C code，5 分鐘內講出 2 個 patch 位置與改法，編譯驗證生成 effective patch.
